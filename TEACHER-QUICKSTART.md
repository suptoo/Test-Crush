# 🎓 Teacher Quick Start - AI Features

## 3-Minute Tutorial

### Step 1: Create a Quiz
1. Login as a teacher
2. Click **"Create New Quiz"** from your dashboard

### Step 2: Use AI Assistant

**Click the "AI Assistant" button** in the top right

#### Try These Examples:

**For Math:**
```
Create 5 algebra questions
```

**For Science:**
```
Generate 10 easy physics questions about motion
```

**For History:**
```
Make 8 medium questions about World War 2
```

**The AI will:**
- ✅ Generate complete questions
- ✅ Create 4 answer choices for each
- ✅ Mark the correct answer
- ✅ Add them to your quiz automatically

### Step 3: Use Math Keyboard

**Click the "Math Keyboard" button** in the top right

#### How to Use:

1. **Click on a question or answer field** (it becomes active)
2. **Browse the tabs:**
   - Basic - Powers, roots, operations
   - Calculus - Integrals, derivatives
   - Trig - sin, cos, tan
   - Greek - α, β, θ, π
3. **Click any symbol** - it inserts automatically!

#### Example:
Type: "What is "
Click: ∫ (integral)
Type: " x² dx?"
Result: "What is $\int x^2 dx$?"

Displays as: What is ∫ x² dx?

### Step 4: Edit & Save

- Edit any AI-generated question
- Modify answer choices
- Add your own questions
- Click **"Save Quiz"**

## 💡 Quick Tips

### AI Assistant Tips

**Be Specific:**
✅ "Create 5 hard calculus questions about limits"
❌ "Make a quiz"

**Include:**
- Number of questions
- Subject/topic
- Difficulty (easy/medium/hard)

**Quick Prompts:**
Use the button shortcuts for instant generation!

### Math Keyboard Tips

**Common Symbols:**
- x² → Powers
- √ → Square root  
- ∫ → Integral
- π → Pi
- α → Alpha
- ± → Plus-minus

**Wrap in $ Signs:**
- Single $: `$x^2$` for inline math
- Double $$: `$$\int x dx$$` for display

**One-Click Examples:**
Use the bottom buttons for common formulas!

## 🚨 Common Questions

### "The AI generated wrong questions"
- Always review and edit AI content
- AI is a starting point, not final
- You can modify any question

### "Math symbols not showing"
- Use $ signs: `$x^2$`
- Click symbols don't type them
- Preview before saving

### "How do I make fractions?"
- Math Keyboard → Fractions tab
- Click "a/b" symbol
- Or type: `$\frac{a}{b}$`

### "Can I mix AI and manual?"
- Yes! Use AI for some questions
- Write others manually
- Best of both worlds

## 🎨 Make It Beautiful

**Good Math Formatting:**
```
✅ The area is $A = \pi r^2$
✅ Factor: $x^2 - 5x + 6$
✅ Evaluate: $\int_0^1 x dx$
```

**Poor Formatting:**
```
❌ The area is A = pi * r^2
❌ Factor: x^2 - 5x + 6
❌ Evaluate: integral from 0 to 1 of x dx
```
